# Software Tester (QA) Assessment

This repository contains my solution for the **Software Tester (QA) Assessment**.

## Assessment Includes

* Test cases for **Registration and Login**
* Test cases for **Task CRUD operations**
* Input validation and error handling
* Identification of possible bugs and risk areas
* Severity and impact analysis

## Testing Approach

The solution covers:

* Positive and negative test cases
* Boundary and edge cases
* Functional testing
* Authentication and authorization
* Data consistency
* Error handling
* End-to-end testing

* `Software_Tester_Assessment.pdf` – Complete assessment solution

## Note

The test cases and possible bugs are based on the requirements provided in the assessment and focus on the main functional, validation, security, and data-related risks.
